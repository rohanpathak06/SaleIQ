# SaleIQ

Grounded commerce intelligence: every demo dashboard, signal, forecast and AI receipt runs with no external services.

## Quick start

`npm install` · `npm run dev` · visit `http://localhost:3000`

Demo identities: `demo@saleiq.app` (owner), `admin@saleiq.app` (admin), and `viewer@saleiq.app` (viewer).

The product includes responsive dashboard, Ask SaleIQ receipts, forecast, segments, inventory signals, scenario planning, sources, reports, billing, settings and administration. The operating layer adds live orders, notifications, orders, products, customers, goals, alert rules, ads, profitability, data health, developers, team activity, status and changelog routes. `GET /api/health` verifies readiness; `GET /api/dev/reconcile` reports demo reconciliation.
