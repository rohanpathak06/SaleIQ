# Simulated features

- Live order events are generated server-side and persisted in browser storage for the demo workspace.
- Sync timing, warnings, connector consent, webhook delivery, exports, invoices and email delivery are simulated.
- Ads, campaign attribution, benchmark cohorts, forecasts, data-quality rows and platform traffic use coherent seeded data.
- API keys, teammates, alert evaluation, report schedules and audit activity are demo-state interactions stored locally.
- Product and customer predictions, AI recommendations, narration and status telemetry are deterministic demo outputs.
